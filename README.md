# 기프티콘 보관 봇

Telegram 사용 방에 올라온 기프티콘과 관련 메시지를 이력 방에 자동 보관하고, OCR 결과와 유효기간을 관리하는 봇입니다.

## 주요 기능

- 사진, 이미지 파일, GIF, 동영상, 일반 텍스트를 이력 방에 자동 보관
- 캡션이 없는 사진·이미지 파일에서 Tesseract OCR로 한글·영문 텍스트 인식
- OCR 텍스트에서 유효기간 자동 추출
- 여러 장의 사진을 한 번에 보내도 각 사진을 개별 보관하고 OCR 처리
- 앨범의 여러 Telegram 업데이트가 겹치지 않도록 보관·OCR·DB 저장을 순차 처리
- OCR 원문을 검색에 보존하면서 목록에는 간결한 브랜드·상품명 요약 표시
- 목록 제목과 유효기간 수동 수정
- 사용 완료 처리 시 사용 방의 원본 메시지 삭제
- 이력 방의 보관 메시지에서 사용 방으로 기프티콘 복구
- 유효기간 임박 알림과 만료 기프티콘 조회
- 유효기간 알림의 기준 기간·발송 시각·활성화 여부를 채팅 명령으로 변경
- 실제 발송과 동일한 형식의 알림 테스트
- SQLite DB 자동 마이그레이션

## 동작 구조

```text
사용 방 메시지
    │
    ├─ 답장 메시지인가? ── 예 ── 기존 기프티콘 관리 명령으로 처리
    │
    └─ 새 메시지 ── 이력 방으로 복사
                    └─ 이미지이고 캡션 없음: 다운로드 → OCR → 유효기간 추출 → DB 저장
```

사진 앨범은 Telegram에서 여러 메시지로 전달됩니다. 봇은 각 메시지를 별도 기록으로 저장하며, 전체 보관 과정은 순차 처리해 첫 번째 사진만 처리되고 나머지가 누락되지 않도록 합니다.

## 명령어

| 명령어 | 설명 |
| --- | --- |
| `/start`, `/help` | 사용법 안내 |
| `/chatid` | 현재 채팅방 ID 확인 |
| `!사용` | 사용 방에서 원본 기프티콘에 답장해 사용 완료 처리 |
| `!복구` | 이력 방의 보관 메시지에 답장해 사용 방으로 복구 |
| `!목록` | 미사용 기프티콘 목록 조회 |
| `!미사용` | 미사용 기프티콘 목록 조회 |
| `!검색 <단어>` | 미사용 기프티콘의 OCR·캡션 내용 검색 |
| `!사용완료` | 사용 완료 기프티콘 목록 조회 |
| `!사용완료삭제 확인` | 이력 방에서 사용 완료 기프티콘과 관련 메시지 전체 삭제 |
| `!임박 [일수]` | 지정 일수 이내 만료 예정 기프티콘 조회. 기본값은 30일 |
| `!만료` | 만료된 미사용 기프티콘 조회 |
| `!알림설정` | 현재 유효기간 알림 설정 조회 |
| `!알림설정 7일 09:00` | 7일 이내 기준, 매일 09:00(KST)으로 설정 |
| `!알림설정 끄기` / `!알림설정 켜기` | 유효기간 알림 끄기·켜기 |
| `!알림테스트` | 현재 설정 기준으로 즉시 알림 테스트 |
| `!알림테스트 7` | 7일 이내 기준으로 즉시 알림 테스트 |
| `!삭제목록` | 사용 완료 기프티콘을 선택해 삭제 |
| `!강제삭제` | 이력 방의 보관 메시지에 답장해 DB와 관련 메시지 삭제 |
| `!초기화 확인` | DB 목록 전체 초기화. Telegram 메시지는 삭제하지 않음 |

### 제목·유효기간 수정

기프티콘 원본 또는 이력 방의 보관 메시지에 답장해 다음 형식으로 입력합니다.

| 입력 | 동작 |
| --- | --- |
| `유효기간 2026-12-31` | 유효기간 수정 |
| `유효기간 6/17` | 현재 연도의 유효기간으로 수정 |
| `유효기간 없음` | 저장된 유효기간 삭제 |
| `제목 스타벅스 아메리카노` | 목록 표시 제목 수정 |
| `제목 없음` | OCR·캡션 기반 자동 요약으로 복원 |
| `스타벅스 아메리카노` | 제목만 수정 |
| `6/17` | 유효기간만 수정 |
| `스타벅스 아메리카노 6/17` | 제목과 유효기간을 함께 수정 |

날짜는 `YYYY-MM-DD`, `YYYY.MM.DD`, `YYYY/MM/DD`, `M/D` 형식을 지원합니다. 제목을 수정해도 OCR 원문은 검색용으로 유지됩니다.

기존 기프티콘에 답장한 메시지는 새 기프티콘으로 보관하지 않습니다. 답장은 사용 완료, 복구, 제목·유효기간 수정 같은 관리 작업에만 사용합니다.

## 유효기간 알림 설정

기본값은 `7일 이내`, `매일 09:00(KST)`, `켜짐`입니다. 설정은 SQLite DB에 저장되므로 봇을 재시작해도 유지됩니다. 설정 변경과 테스트 명령은 이력 방에서만 실행할 수 있습니다.

```text
!알림설정                  현재 설정 확인
!알림설정 7일 09:00        기준 기간과 발송 시각 변경
!알림설정 14 08:30         같은 설정을 숫자로도 입력 가능
!알림설정 08:30            발송 시각만 변경
!알림설정 14일             기준 기간만 변경
!알림설정 끄기             정기 알림 중지
!알림설정 켜기             정기 알림 재개
!알림테스트                현재 설정으로 즉시 발송
!알림테스트 7              7일 이내 기준으로 즉시 발송
```

`!알림테스트`는 실제 알림 메시지를 사용 방으로 보내지만, 당일 발송 기록은 남기지 않습니다. 따라서 테스트 때문에 같은 날 정기 알림 대상에서 제외되지 않습니다. 대상 쿠폰이 없으면 알림을 보내지 않고 결과만 안내합니다.

## 최초 설정

1. BotFather에서 봇을 만들고 토큰을 발급합니다.
2. 사용 방과 이력 방에 봇을 추가합니다.
3. 봇에 메시지 읽기·복사·삭제 권한을 부여합니다. 사용 완료 처리 시 사용 방 원본 메시지를 삭제할 수 있어야 합니다.
4. BotFather의 `/setprivacy`에서 Privacy Mode를 `Disable`로 설정합니다.
5. 각 채팅방에서 `/chatid`를 실행해 ID를 확인합니다.
6. `.env.example`을 `.env`로 복사하고 값을 입력합니다.

```env
TELEGRAM_BOT_TOKEN=실제_BotFather_토큰
GIFTICON_ACTIVE_CHAT_ID=-1001234567890
GIFTICON_ARCHIVE_CHAT_ID=-1009876543210
GIFTICON_DB_PATH=gifticons.db
```

현재 코드는 Telegram 사용자별 관리자 권한을 검사하지 않고, 명령이 지정된 사용 방 또는 이력 방에서 전송되었는지만 확인합니다. 따라서 `!강제삭제`, `!삭제목록`, `!사용완료삭제 확인`, `!초기화 확인`은 신뢰할 수 있는 사용자만 사용할 수 있도록 채팅방 멤버 권한을 제한해야 합니다.

## 로컬 실행 (Windows)

Tesseract OCR과 한국어 언어 데이터가 필요합니다.

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
Copy-Item .env.example .env
# .env에 실제 값을 입력
python bot.py
```

```powershell
python -m py_compile bot.py storage.py

```

## QNAP Docker 실행

Docker 이미지에는 `tesseract-ocr`와 `tesseract-ocr-kor`가 포함됩니다. SQLite DB는 호스트 볼륨에 저장하는 것을 권장합니다.

```bash
docker build -t gifticon-archive-bot .
docker run -d --name gifticon-archive-bot \
  --restart unless-stopped \
  -e TELEGRAM_BOT_TOKEN="YOUR_TOKEN_HERE" \
  -e GIFTICON_ACTIVE_CHAT_ID="-1001234567890" \
  -e GIFTICON_ARCHIVE_CHAT_ID="-1009876543210" \
  -v /share/Container/gifticon_bot_data:/data \
  gifticon-archive-bot
```

Docker 실행 시 `GIFTICON_DB_PATH`를 지정하지 않으면 `/data/gifticons.db`를 사용합니다.

## 제한 및 참고사항

- OCR은 캡션이 없는 이미지에 이미지당 한 번 실행됩니다.
- 10MB를 초과하는 파일과 2,000만 픽셀을 초과하는 이미지는 OCR을 생략합니다.
- OCR 타임아웃은 이미지당 15초입니다.
- OCR 결과는 최대 1,500자까지 저장합니다.
- OCR은 이미지 품질에 따라 결과가 달라질 수 있습니다. 유효기간을 인식하지 못하면 `유효기간 미인식`으로 표시됩니다.
- 같은 이미지를 여러 번 올리면 각각 별도의 기록으로 저장됩니다.
- `!초기화 확인`은 DB만 비우며 이력 방의 Telegram 메시지는 삭제하지 않습니다.
- 만료 알림은 매일 오전 9시(KST)에 실행되며 한 번에 최대 50개까지 전송합니다.
- 만료 알림의 기본 설정은 7일 이내·09:00(KST)이며 `!알림설정`으로 변경할 수 있습니다.
- `.env`, 실제 토큰, SQLite DB 파일은 Git에 커밋하지 마세요.
